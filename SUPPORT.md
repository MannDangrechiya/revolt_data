## 2. GitHub Issue Tracker

For bug reports, feature requests, or hardware validation feedback:

- 🐛 [Report a Bug](.github/issue_template/bug_report.md) — File a bug report if you encounter an unexpected crash or UI error.
- ✨ [Request a Feature](.github/issue_template/feature_request.md) — Propose a new feature or enhancement.
- 🏍️ [Hardware Validation Report](.github/issue_template/hardware_validation.md) — Submit telemetry logs or hardware test results from a physical Revolt RV400 vehicle.
