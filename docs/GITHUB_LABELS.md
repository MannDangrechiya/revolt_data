# GitHub Labels Reference Guide

This document defines the standardized GitHub issue and pull request label taxonomy used across the Revolt EV ecosystem repositories (`revolt_data`, `revolt_ble_sdk`, `revolt_ble_toolkit`).

---

## Label Categories & Color Standards

| Label Name | Description | Color | Category |
| :--- | :--- | :---: | :--- |
| `bug` | Software defects, exceptions, or unexpected runtime crashes | `#d93f0b` | Defect |
| `enhancement` | New feature requests or architectural improvements | `#a2eeef` | Feature |
| `documentation` | Improvements, updates, or additions to documentation | `#0075ca` | Metadata |
| `hardware` | Real Revolt RV400 vehicle hardware testing & logs | `#e99695` | Hardware |
| `BLE` | Bluetooth Low Energy stack, GATT, or connection issues | `#1d76db` | Protocol |
| `parser` | HCI Snoop / ATT / GATT parser modules | `#c5def5` | Protocol |
| `SDK` | Standalone `revolt_ble_sdk` Dart package | `#5319e7` | Component |
| `app` | `revolt_data` Flutter mobile application | `#006b75` | Component |
| `backend` | Database, state providers, or offline storage logic | `#bfd4f2` | Component |
| `security` | Security, credential stripping, or data exposure reports | `#b60205` | Security |
| `performance` | Memory leaks, frame rates, or query latency issues | `#d4c5f9` | Quality |
| `good first issue` | Good for newcomers to the project | `#7057ff` | Onboarding |
| `help wanted` | Open issues seeking community contributions | `#008672` | Community |
